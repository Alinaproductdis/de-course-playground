# de-course-playground

## Про мене

Привіт! Мене звати Аліна Канівець, я продуктова дизайнерка з Києва.
Понад п'ять років я проєктую інтерфейси для мобільних застосунків і вебсервісів, а найбільше люблю складні продукти, які треба зробити простими.
Зараз я вчуся на курсі з Design Engineering, щоб краще розуміти код і самій втілювати свої дизайни.
Цей репозиторій — моя пісочниця для навчальних завдань і експериментів.
У вільний час я п'ю забагато кави, колекціоную гарні шрифти й фотографую міську архітектуру.
Мрію колись створити власний невеликий застосунок від ідеї до релізу.
